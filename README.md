# BrutalBudget

Aplikasi web pencatat keuangan personal dengan desain **Brutalist** yang responsif.

## Fitur awal
- Tambah transaksi pemasukan/pengeluaran
- Ringkasan pemasukan, pengeluaran, saldo
- Riwayat transaksi
- UI brutalist (border tegas, kontras tinggi, shadow blok)

## Jalankan lokal
```bash
cd /home/tik/personal-finance-brutalist
python3 -m http.server 8080
```
Buka: http://localhost:8080

## Workflow Git yang dipakai
- branch per task (`feat/...`, `fix/...`)
- commit kecil dengan conventional commit
- test/cek manual dulu sebelum commit
